# 公开版验收用例

## 正向
1. 新用户完成授权，创建自己的课程。
2. iPhone 前台开始、暂停、继续、结束录音，时钟扣除暂停时间。
3. 录音期间拍摄课件，照片带准确的录音相对时间。
4. 断网后保留本地待上传资料，恢复联网后幂等上传。
5. 同一账号在 ChatGPT 读取真实照片和现有讲稿，生成并保存笔记。

## 负向与安全
1. 未授权用户调用 MCP 或直接访问素材 API 必须拒绝。
2. 用户 A 使用用户 B 的课程 ID、照片 ID、音频对象地址或笔记 ID，读取和修改均必须拒绝。
3. 麦克风/相机权限拒绝、录音中断、存储不足及没有讲稿时，应明确报错且不能捏造转写。

## 发布门槛
自动化测试、两账号隔离测试、真机测试、隐私政策与服务条款审核、部署回滚演练全部通过后再提交公开审核。测试结果应记录设备、系统版本、时间和证据，不得以本地单元测试替代真机验收。
