# 课伴 · Course Partner

免费、MIT 开源的本地课堂采集原型：浏览器录音、随手拍课件、导出文件。**不需要 ChatGPT 插件、账号或模型 API。**

## 快速运行

安装 Node.js 22 或更新版本，下载或克隆本仓库后运行：

```sh
node scripts/local.mjs
```

打开终端显示的 http://127.0.0.1:8787 。无需 npm install。不要直接双击 HTML，浏览器模块与存储需要 HTTP 来源。

1. 输入课堂名，点击「开始录音」，按浏览器提示授权麦克风。
2. 点击「打开相机」，授权后拍照。相机只请求视频，不重新申请麦克风。
3. 点击「结束并保存」，分别导出录音、照片和课堂索引 JSON。索引保存照片时刻与音频片段时间，方便对应讲解。
4. 如需 AI 整理，**由你自己在 ChatGPT 或其他工具中添加导出的文件**。本项目不连接 ChatGPT、不自动上传，不保证任一平台支持长音频或自动转写。

## 数据与隐私

录音、照片、课堂名和时间保存在当前浏览器 IndexedDB。本页面没有上传接口、远程模型调用、统计 SDK 或插件文件桥；不会向作者的私人站点同步。静态网页托管者仍可能保存普通访问日志。

浏览器清理、配额回收、隐私模式、卸载或设备损坏可能丢失资料，请及时导出。没有账户隔离或本地加密，共用浏览器配置的人可能访问记录。删除本地课堂不删除已导出文件、备份或你自行上传的附件。请遵守课堂录音与拍摄规则并获得必要许可。

## 手机使用与限制

- 本地服务器仅监听电脑回环地址，**手机不能通过自己的 127.0.0.1 访问电脑**。手机试用需自行将 `local-only/` 文件夹部署到支持 HTTPS 的静态托管服务；本仓库没有已验证的公共在线服务。
- 录音需前台使用；锁屏、切后台、来电或浏览器回收可能中断。没有五小时可靠性保证。
- 本轮验证为自动化测试与桌面检查，不代表 iPhone 真机录音、相机并行或长时间验收。
- 不提供实时转写、图片 OCR、自动笔记生成或 ChatGPT Voice 控制。
- 页面目前逐文件导出，不提供 ZIP 打包或跨设备同步。浏览器可能要求允许下载。
- 音频按浏览器容器分组导出，刷新后不会无缝继续旧录音。照片压缩为最长宽度 1600 像素 JPEG。
